# 🏋️ Powerhouse The Gym

A modern and responsive gym website built to provide an engaging online experience for gym members and visitors.

## 🌐 Live Demo

[Visit Live Website](https://powerhousethegym.site.je/?i=2)

## ✨ Features

- 🏠 Modern homepage
- 💪 Gym services and programs
- 🏋️ Training information
- 👨‍🏫 Trainer section
- 💳 Membership plans
- 📱 Fully responsive design
- 📞 Contact section (whatsapp/contact form)
- 🎨 Modern and user-friendly UI

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
